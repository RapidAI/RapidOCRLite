# RapidOCRLite logo

- `rapidocrlite_logo.svg` / `.png`: light-background logo, no tagline (used in README.md / README-CN.md)
- `rapidocrlite_logo_dark.svg` / `.png`: dark-background version
- `logo_C*.svg` / `.png`: the same logo with the English tagline "Lightweight open source OCR, pure C/C++"

The text is converted to outlines. The font is **Nunito** (Vernon Adams, Cyreal, Jacques Le Bailly), licensed under the **SIL Open Font License 1.1 (OFL-1.1)**.
The design is derived from the RapidAI RapidOCR logo (navy wordmark and yellow lightning bolt); that brand belongs to the RapidAI project.
Colours: navy #2B2F8F, yellow #F0BE45.
